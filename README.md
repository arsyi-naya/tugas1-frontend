# Wisata Alam

Nama: Arsyifa Nazhaya Yazwa

## Tema
Katalog Wisata Alam 
Ini merupakan katalog yang menampilkan berbagai destinasi wisata alam, dengan kategori danau, pantai, lembah, air terjun, dan gunung. Setiap kartu menampilkan nama tempat wisata, kategori wisata, harga tiket masuk, serta apakah tempat wisata tersebut buka atau tutup.

## Cara Menjalankan
1. npm install
2. npm run dev
